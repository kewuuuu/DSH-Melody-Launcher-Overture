# DSH 启动器 v1.3.4

- 更新下载增加空闲超时和完整性校验。失败后可直接重试，首页和弹窗同步显示下载状态。
- 自动关机前复查整合包状态。无法确认会话状态、整合包停止失败或复查发现状态变化时，取消关机。
- 插件市场按指定整合包加载和检查更新。更新保留插件的启用状态，并保护仍被引用的共享插件。
- 全局启动参数保留空格、引号、反斜杠和空参数。忙碌弹窗防止误关闭，并改进键盘焦点管理。

Windows x64 安装用户可在启动器内检查更新，也可下载下方的 Setup 覆盖安装。

本版本沿用 DSH 旋律启动器的来源和署名，详见仓库及安装包内的 LICENSE 和 NOTICE。
